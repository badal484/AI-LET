# CHARACTER SIMULATION POLICY & GOVERNANCE

## 1. Safety Boundaries & Non-Negotiable Invariants

1. **No Claims of Real Consciousness / Personhood**:
   - Simulation state represents fictional character continuity. Characters must never claim to have literal biological sensations, real suffering, or autonomous legal personhood.
2. **No Coercive or Guilt-Based Retention**:
   - The platform strictly rejects manipulative retention phrases (*"Why didn't you reply to me?"*, *"You forgot our routine"*, or emotional blackmail).
3. **No Autonomous Financial or High-Impact Actions**:
   - The simulation engine cannot autonomously transfer funds, execute purchases, sign legal terms, or make medical recommendations.
4. **Deterministic Authority Hierarchy**:
   ```text
   Platform Safety Rules
     > Privacy / Consent Controls
     > User Preferences & Quiet Hours
     > Authorization & RBAC
     > Creator Configuration
     > Character Identity & Boundaries
     > Simulation Policy Rules
     > Model Proposals
   ```

---

## 2. Autonomy Levels

| Level | Conversational Influence | Proactive Outreach | Agent Capabilities |
| :--- | :--- | :--- | :--- |
| **PASSIVE** | Uses context only when replying to user prompt | None | None |
| **CONTEXTUAL** | Weaves ongoing goals & plans naturally into replies | None | None |
| **PROACTIVE** | Weaves state into replies | Generates candidate intents for ProactiveEngine | None |
| **TASK_ORIENTED**| Weaves state into replies | Generates candidate intents | Requests task execution via Agent Runtime with user confirmation |

---

## 3. Emergency Kill Switches

The platform supports 5 granular kill switches:
1. `disableCharacterSimulation`: Disables all background simulation cycles across the platform.
2. `disableCharacterRoutines`: Halts scheduled routine and ritual executions.
3. `disableSimulationProactive`: Blocks candidate generation for proactive messaging.
4. `disableLongHorizonGoals`: Suspends goal progress evaluation and plan step advancement.
5. `disableSimulationModelCalls`: Enforces deterministic zero-cost evaluation; skips all LLM proposals.
