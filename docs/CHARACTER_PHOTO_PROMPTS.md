# Character photo prompts (ChatGPT image generation)

Two photos per character, of the **same person**:

| Photo | Size in ChatGPT | Used for | Save as |
|---|---|---|---|
| 1. Cover | Portrait, 1024×1536 (2:3) | Home cards, top of the character page | `<slug>-cover.png` |
| 2. Profile photo | Square, 1024×1024 | Chats list, chat header, bubbles | `<slug>-avatar.png` |

## How to use

1. Open a **new ChatGPT chat for each character** (so faces don't mix between characters).
2. Paste the **style block** below, then that character's **cover** prompt.
3. When you like the cover, in the **same chat** paste the **profile photo** prompt — it asks for the same
   person, so the face matches (this fixes the Ritika problem: avatar and cover were different women).
4. Save both into one folder, named `<slug>-cover.png` and `<slug>-avatar.png` (slug is in each heading).

Check every result: hands and fingers look normal, no text or logos, the face is the same in both photos,
and the person looks like the age written. Regenerate if not.

## Style block (paste first, every time)

```
Photorealistic photo of a fictional person (not a real person, not a celebrity or influencer). It must look
like a real candid photo taken on a good phone camera: natural skin texture with pores, no beauty filter, no
airbrushing, natural light, slight depth of field. Indian person, modern India, 2020s. Fully clothed, tasteful,
nothing suggestive. No text, no logos, no watermark, no frames, no extra people in focus. Hands relaxed and
natural if visible.
```

## Profile photo prompt (photo 2, same chat, after the cover)

Replace `[expression]` with the one given for that character.

```
Now the same person — exactly the same face, hair, skin tone and age — in a close-up head-and-shoulders photo,
square 1:1. Face centred and filling about 60% of the frame, eyes at the upper third, [expression], looking at
the camera. Plain softly blurred background from the same place, good even light on the face. Same clothes.
```
